2. Guia de Atributos por Elemento

            


            
            

                
                
                

                    

                        
<polyline>

                        Linhas Conectadas
                    

                    
Desenha uma série de segmentos de reta conectados, geralmente sem preenchimento.

                    
    
                        
  • points: Lista de coordenadas $x,y$ (Ex: "50,150 150,50 250,150").
    • 
                    

                


                
                

                    

                        
<polygon>

                        Formas Fechadas
                    

                    
Semelhante à polilinha, mas o navegador conecta automaticamente o último ponto ao primeiro.

                    
    
                        
  • points: Coordenadas $x,y$ das extremidades de cada aresta.
    • 
                    

                


                
                

                    

                        
<g>

                        Grupo
                    

                    
Agrupa múltiplos elementos SVG para aplicar herança de estilos CSS ou transformações geométricas.

                    
    
                        
  • transform: Aplica translate, scale, rotate ou skew ao grupo de uma vez.
    • 
                    

                


                
                

                    

                        
<linearGradient>

                        Gradientes
                    

                    
Define uma transição suave entre múltiplas cores a ser usada no preenchimento de formas.

                    
    
                        
  • x1 / y1: Ponto inicial do vetor de gradiente.
    • 
                        
  • x2 / y2: Ponto final do vetor de gradiente.
    • 
                        
  • <stop>: Define as cores e posições da transição.
    • 
                    

                


                
                

                    

                        
<clipPath>

                        Recorte
                    

                    
Oculta as partes de um elemento que ficam de fora da silhueta da forma de recorte definida.

                    
    
                        
  • id: Identificador usado para chamar no CSS via `clip-path: url(#id)`.
    • 
                    

                


                
                

                    

                        
<mask>

                        Máscara
                    

                    
Combina o canal de alfa (transparência) e cores (branco revela, preto esconde) para mascarar elementos.

                    
    
                        
  • id: Usado via propriedade CSS `mask: url(#id)`.
    • 
                    

                


                
                

                    

                        
<filter>

                        Efeitos
                    

                    
Permite aplicar efeitos visuais de pós-processamento como desfoques e sombras ao vetor.

                    
    
                        
  • <feGaussianBlur>: Executa o filtro de desfoque.
    • 
                        
  • stdDeviation: O raio de intensidade do desfoque.
    • 
                    

                


                
                

                    

                        
<animate>

                        Animação
                    

                    
Anima atributos de geometria ou estilo do elemento pai diretamente de forma nativa e síncrona.

                    
    
                        
  • attributeName: Nome do atributo alvo (Ex: "cx").
    • 
                        
  • dur / repeatCount: Duração e quantidade de repetições.
    • 
                        
  • from / to: Estados inicial e final do valor.
    • 
                    

                


                
                

                    

                        
<foreignObject>

                        Interoperabilidade
                    

                    
Permite integrar elementos HTML nativos (divs, inputs, CSS) diretamente no espaço XML do SVG.

                    
    
                        
  • width / height: Tamanho da janela para o HTML renderizado.
    • 
                        
  • xmlns: Namespace XHTML (`http://www.w3.org/1999/xhtml`).
    • 
                    

                


            

        


        
        

            

                
                
3. Estilização CSS Especializada para SVG

            

            
            

                Muitas propriedades que usamos em elementos HTML comuns (como background-color ou border) **não funcionam** em elementos internos do SVG. O SVG possui propriedades de estilo CSS exclusivas. Veja as principais a seguir:
            


            

                

                    
                        

                            Propriedade CSS
                            Alternativa ao HTML
                            Valores Aceitos
                            Descrição de Efeito
                        

                    
                    
                        

                            fill
                            background-color
                            Cores CSS, url(#idGradiente)
                            Define a cor interna de preenchimento da forma geométrica.
                        

                        

                            fill-opacity
                            opacity (do fundo)
                            0.0 a 1.0
                            Altera apenas a opacidade do preenchimento interno, sem afetar as bordas.
                        

                        

                            stroke
                            border-color
                            Cores CSS, gradients
                            Define a cor da borda/linha do elemento gráfico.
                        

                        

                            stroke-width
                            border-width
                            Valores numéricos ou px, em, rem
                            Define a espessura da borda.
                        

                        

                            stroke-dasharray
                            border-style (dashed)
                            Lista de valores separados por vírgula (ex: "5, 5")
                            Transforma a borda sólida em linhas pontilhadas ou tracejadas customizadas.
                        

                        

                            stroke-dashoffset
                            Não possui
                            Números (ex: 100)
                            Desloca o ponto de partida do tracejado (fundamental para efeito de "desenhar linha").
                        

                        

                            stroke-linecap
                            Não possui
                            butt, round, square
                            Altera o formato visual das extremidades de linhas abertas.
                        

                        

                            vector-effect
                            Não possui
                            non-scaling-stroke, none
                            Se definido como "non-scaling-stroke", impede que a borda engrosse se o SVG sofrer zoom ou redimensionamento.
                        

                    
                

            

        


        
        

            

                
                
4. O Segredo do Namespace no JavaScript

            


            

                

                    Ao criar elementos gráficos SVG via JavaScript de forma dinâmica, a função padrão document.createElement() cria elementos no namespace de documentos HTML convencionais. Se você usá-la, os seletores SVG serão renderizados no DOM, mas **não aparecerão na tela** porque o navegador falhará ao tratá-los como elementos gráficos vetoriais.
                

                

                    Para resolver isso, você precisa usar document.createElementNS() com o namespace do SVG de forma estrita.
                


                
                

                    

                        A Maneira Correta (Sim!)
                        
const SVG_NS = "http://www.w3.org/2000/svg";
const circulo = document.createElementNS(SVG_NS, "circle");
circulo.setAttribute("cx", "150");
circulo.setAttribute("cy", "150");
circulo.setAttribute("r", "50");
document.getElementById("meu-svg").appendChild(circulo);

                    


                    

                        A Maneira Errada (Não funciona!)
                        
// O navegador não renderiza o elemento
const circulo = document.createElement("circle");
circulo.setAttribute("cx", "150");
circulo.setAttribute("cy", "150");
circulo.setAttribute("r", "50");
document.getElementById("meu-svg").appendChild(circulo);
